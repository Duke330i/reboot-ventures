# Reboot Ventures - AI Transformation Consulting

Complete Astro website for Reboot Ventures.

## Quick Start

1. **Extract this ZIP**
2. **Install:** `npm install`
3. **Add assets:**
   - Copy `logo.png` to `public/`
   - Copy team headshots to `public/images/team/`
4. **Run:** `npm run dev`
5. **Visit:** http://localhost:4321

## Ready to Deploy

When done testing locally:
```bash
git init
git add .
git commit -m "Reboot Ventures site"
gh repo create reboot-ventures-site --private
git push -u origin main
```

Then connect to Vercel for auto-deployment.
